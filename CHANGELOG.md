# Change log

## 0.8.1

### Fixed

- Improved junk and Keyring categorization in Category View.
- Kept junk-marked items in the intended Junk group and handled Keyring items more reliably.

## 0.8.0

### Added

- Name-based material grouping for Category View, including herbs, cloth, leather, ores, enchanting materials, elementals, engineering parts, and gems when item subtype data is missing.
- A Category gap setting.

### Changed

- Added an Empty Slots button to the bag bar.
- One-item headings now keep seven letters, while larger groups keep their full names.
- Replaced selected-list Up/Down controls with Top/Bottom buttons; drag-and-drop reordering remains available.

### Fixed

- Removed the duplicate Collapse Empty Slots option from Category Settings.
- Separated Import status from Close in the settings panel.
